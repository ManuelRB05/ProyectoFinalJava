# Proyecto Final Java - Globant

Proyecto final del módulo de Java Basics. Es un sistema en consola para llevar el control de una universidad: profesores, estudiantes y clases.

## Menú principal

1. Listar todos los profesores con sus datos.
2. Listar todas las clases y, desde un submenú, ver el detalle de una clase (profesor y estudiantes incluidos).
3. Crear un estudiante nuevo y agregarlo a una clase existente.
4. Crear una clase nueva, asignándole un profesor y estudiantes ya existentes.
5. Buscar un estudiante por id y ver en qué clases está inscrito.
6. Salir.

## Conceptos aplicados

- Herencia y polimorfismo (`Teacher` como clase base de `TeacherFullTime` y `TeacherPartTime`, cada una con su propio cálculo de salario).
- Encapsulamiento y modificadores de acceso en todas las clases del modelo.
- Constructores y atributos/métodos estáticos.
- Separación en paquetes (`app` para la aplicación, `model` para las entidades).
